## .NET Conf 2026 | Building the Next Generation of .NET Applications
From Modern .NET to AI-Native & Cloud-Native Engineering
.NET is evolving rapidly—from a powerful application development platform into a foundation for building cloud-native, distributed, and AI-powered applications.
Join us for .NET Conf 2026, a hands-on technical community event exploring the latest trends, tools, patterns, and engineering practices shaping the future of .NET development.
This event is designed for developers, software engineers, architects, technical leads, and technology enthusiasts who want to go beyond the basics and understand how modern .NET is being used to build intelligent, scalable, production-ready systems.

## 🎯 What You'll Learn

During the event, we'll explore the journey from traditional .NET development to modern AI-powered engineering:

- What's new and evolving in the modern .NET ecosystem
- Modern C# development practices and productivity techniques
- Building cloud-native applications with .NET
- .NET Aspire and distributed application development
- Integrating AI into .NET applications
- Building AI-powered applications and intelligent features
- AI agents and agentic application architecture
- GitHub Copilot for modern .NET development
- AI-assisted coding, testing, debugging and refactoring
- Designing scalable and resilient .NET architectures
- Observability and production readiness
- Enterprise development patterns and best practices
